## ⚙️ 실행 방법

각 폴더로 이동하거나 폴더 경로를 포함하여 터미널에서 파일을 실행할 수 있습니다.

**예시 1: 경로를 직접 지정해 실행하기**
```bash
python 01_datatypes/practice.py
```

**예시 2: 폴더로 이동 후 실행하기**
```bash
cd 01_datatypes
python practice.py
```
